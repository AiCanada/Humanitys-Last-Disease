# Live post-generation screening review

> **Local evidence boundary:** Receipt names and command lines in this review document the local
> verification session. `outputs/method-review/` is intentionally ignored and is not published in
> this repository. Those paths are provenance labels, not download links; commands that name them
> require independently obtained, licence-compatible inputs, tools, models, and assets.

As of 2026-11-23, **60 distinct screening methods or evidence readers produced live output**. The original review covered 55. Subsequent reviews added PRODIGY protein-pair affinity, AutoDock Vina fixed-pose scoring, Therapeutic Nanobody Profiler, QupKake microscopic pKa and SyGMa metabolite prediction. Every method received a negative, malformed, ambiguous, or perturbed input, or a repeatability challenge on the same input. Several also had independent numerical comparisons. Predictive accuracy across new designs remains unmeasured.

The review checked 118 local evidence files against their SHA-256 digests. Some methods compute a prediction or structural measurement; others read or verify experimental evidence or a completed calculation. A working reader establishes that the software can interpret the supplied evidence, not that it predicts new candidates accurately. Use the finished-run command and each method's documented input contract to reproduce a screen. [Screen inputs](reference/screen-inputs.md)

Thirteen additional adapters, configurations, planners or provider access checks produced no standalone scientific result. Method selection came from implemented entry points in the checkout. The original 1,496-row catalogue snapshot updated 41 implementation cells. The later 1,500-row catalogue records PRODIGY, AutoDock Vina, Therapeutic Nanobody Profiler, QupKake and SyGMa on their respective rows. Repeated runs, integration checks and dataset aliases contribute no additional method to the count. ### Chemprop validation
